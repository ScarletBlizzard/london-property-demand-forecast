## 📌 О проекте

Спрос на недвижимость — ключевой индикатор состояния экономики и основной фактор, определяющий
динамику цен и инвестиционную привлекательность рынка. Точный прогноз спроса позволяет
регуляторам, инвесторам и девелоперам принимать обоснованные решения по планированию
строительства, инвестициям и управлению рисками.

Мы решаем **задачу регрессии**: предсказать общий спрос на недвижимость в **районах Лондона**
на основе исторических и текущих данных.

| | |
| --- | --- |
| **Регион исследования** | Районы Лондона, Великобритания |
| **Тип задачи** | Регрессия (ML → DL) |
| **Целевая переменная** | Количество сделок с недвижимостью — аренда, ипотека, покупка в собственность |
| **Признаки** | Макроэкономические, демографические, рыночные, пространственные; тональность новостей (NLP) |

## 🗺️ План работы

- [ ] **Сбор первичных данных** из [источников](primary-data/README.md) в [БД первичных данных](primary-data/DB.md)
- [ ] **Формирование итогового датасета** на основе первичных данных — с максимально возможным количеством признаков
