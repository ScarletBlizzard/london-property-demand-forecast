# Датасет: продажи жилья по районам Лондона

Таргеты: число продаж `sales_count` и медианная цена продажи квартиры `price_median`.
Обучаем две отдельные модели линейной регрессии с одинаковыми признаками для двух этих таргетов.

|  |  |
| --- | --- |
| Период | июнь 2010 — сентябрь 2025 (184 месяца) |
| География | 33 боро Лондона (включая City of London) |
| Ключ | `borough_code` + `month` |
| Данные для EDA ноутбука | [data/borough-month.csv](data/borough-month.csv) |

## Колонки

| Колонка | Роль | Содержание |
| --- | --- | --- |
| `month` | Ключ | Дата в первый день месяца |
| `borough` | Лейбл | Название района |
| `borough_code` | Ключ | Код района по ONS |
| `sales_count` | Первый таргет | Число зарегистрированных продаж за месяц |
| `price_median` | Второй таргет | Медианная цена этих продаж, £ |
| `sales_count_lag12` | Признак | Продажи в этом же районе год назад: для учета сезонности продаж |
| `price_median_lag12` | Признак | Медианная цена в том же районе год назад, £ - сезонный ориентир, как и `sales_count_lag12` |
| `year` | Признак | Календарный год, для долгосрочной годовой динамики |
| `month_num` | Признак | Номер месяца 1–12, для учёта сезонности продаж |
| `ptal` | Признак | Индекс транспортной доступности: используем данные tfl, однако они их апдейтят очень редко |
| `crime_per_1000_lag2` | Признак | Преступления из MPS за M−2 на 1 000 жителей. Данные за M−1 [выходят до 6-го числа](https://data.london.gov.uk/dataset/mps-monthly-crime-dashboard-data-e5n6w), поэтому на 1-е ещё нет гарантии, что данные уже доступны |
| `rooms_median_epc_prev_year` | Признак | Медианное число жилых комнат по сертификатам EPC за Y−1; прошлый год берём, чтобы не использовать будущие данные |
| `flat_area_median_epc_prev_year` | Признак | Медианная площадь квартир, м², по сертификатам EPC за Y−1 |
| `energy_efficiency_median_epc_prev_year` | Признак | Медианный текущий балл энергоэффективности EPC за Y−1; выше — эффективнее, это не проценты! |
| `energy_consumption_median_epc_prev_year` | Признак | Медианное расчётное энергопотребление за Y−1, кВт·ч/м² в год; это не показания счётчика! |
| `floor_height_median_epc_prev_year` | Признак | Медианная высота помещений (от пола до потолка) по EPC за Y−1, м |
| `bank_rate` | Признак | Ставка Банка Англии, %: последнее дневное значение до начала месяца, без будущих изменений ставки за этот месяц |
| `mean_pay_prev_year` | Признак | Средняя годовая зарплата gross за Y−1, £: ASHE [публикуется осенью отчётного года](https://www.ons.gov.uk/releases/employeeearningsintheuk2024) |
| `population_prev_2_years` | Признак | Население за Y−2, человек: оценки за Y−1 [публикуются в следующем году](https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationestimates/methodologies/midyearpopulationestimatesqmi) и в январе Y ещё неизвестны |

Для City of London отсутствует преступность MPS; в зарплатах также
бывают неопубликованные оценки. Нулями эти значения не заменялись.

Оба таргета описывают **текущий месяц**: ни один из них нельзя включать
в признаки другой модели. Например, при прогнозе цены
нельзя использовать `sales_count` за прогнозируемый месяц.

Также важно, что ключи и лейблы нужны только для выводов графиков в EDA и не должны использоваться как признаки для обучения модели.

## Откуда берутся данные

- **Продажи и цены:** `primary.hm_land_registry__price_paid`, только
  `ppd_category_type = 'A'` — стандартные сделки категории A. Продажи за наличные
  и с ипотекой уже входят в этот счётчик. Это наблюдаемый оборот рынка,
  используемый как показатель спроса. Медиана цены продажи менее чувствительна к очень дорогим сделкам, чем среднее,
  но всё равно зависит от состава проданных объектов.
- **PTAL:** до января 2023 берём готовый `av_ptai_2015` по району из
  `primary.tfl__ptal_borough_2015`. С января 2023 используем среднее `mean_ai` по LSOA района из
  `primary.tfl__ptal_lsoa_2023`, группируя напрямую по `borough` из источника. Источника по borrough для 2023 tfl не публиковали, только по LSOA. Значения PTAL: 0–6b (от худшего к лучшему)
- **Преступность:** `primary.mps__crime_borough`, сумма по всем категориям
  преступлений в районе за месяц M−2. Непривязанные к боро категории вроде Heathrow не
  присоединяются. Делим на `population_prev_2_years` и умножаем на 1 000, чтобы сравнивать
  районы разного размера. Это зарегистрированные преступления, а не вероятность
  стать жертвой преступления: численность приезжающих в район не учитывается.
- **Характеристики жилья EPC:** `primary.epc__domestic`, `GROUP BY` по району и году
  регистрации сертификата (`lodgement_date`). Считаем медиану
  `number_habitable_rooms` по всем типам жилья и медиану `total_floor_area`
  только для `property_type = 'Flat'`. `NULL` и `0` комнаты и площади не участвуют в соответствующей медиане.
  Для месяцев года Y присоединяем значения за Y−1: например, для 2017 года — сертификаты, зарегистрированные
  в 2016 году. Тем же способом считаем медианы `current_energy_efficiency`,
  `energy_consumption_current` и `floor_height` по всем типам жилья.
  Балл энергоэффективности интерпретируется как [EPC score](https://www.ons.gov.uk/peoplepopulationandcommunity/housing/articles/energyefficiencyofhousinginenglandandwales/2024):
  выше — эффективнее; значения выше 100 автоматически не отбрасываются.
  Единицы энергопотребления и высоты — по [словарю EPC](https://get-energy-performance-data.communities.gov.uk/guidance/data-dictionary).
  Пустая или нулевая высота и неположительные баллы энергоэффективности
  не участвуют в медианах. Для энергопотребления сохраняем числовые значения
  источника, включая нулевые и отрицательные. Энергопоказатели — оценки EPC,
  а не данные счётчиков.
  Внутри года признаки постоянны. Дедупликации по сертификатов нет.
- **Ставка Банка Англии:** `primary.bank_of_england__raw`, серия
  `IUDBEDR` ([описание серии](https://www.bankofengland.co.uk/boeapps/database/FromShowColumns.asp?SearchText=IUDBEDR&Travel=NIx)).
  Берём последнее дневное значение предыдущего месяца. Например, для ноября
  2024 это 5%.
- **Средняя зарплата:** `primary.nomis__earnings_raw`, ASHE, `SEX_NAME = 'Total'`,
  `PAY_NAME = 'Annual pay - gross'`, `ITEM_NAME = 'Mean'`, `MEASURES_NAME = 'Value'`.
  Это среднее арифметическое за год, не медиана и не месячная зарплата.
- **Население:** `primary.nomis__population_raw`, `SEX_NAME = 'Total'`,
  `AGE_NAME = 'All ages'`, `MEASURES_NAME = 'Value'`.
- **Справочник районов:** берём напрямую из `primary.tfl__ptal_borough_2015`, где коды и названия
  всех 33 районов.

Описание и ссылки на первичные источники: [primary-data/README.md](../primary-data/README.md).


## Почему выбраны такие границы датасета и лаги

Нижняя граница — июнь 2010, потому что загруженный MPS начинается с апреля 2010,
а преступность используется с лагом два месяца. Продажи и их годовые лаги,
EPC за прошлый год, зарплата, население и ставка на этом периоде доступны.

Последние месяцы Price Paid могут быть недозаполнены из-за задержки регистрации,
поэтому при обновлении данных нельзя автоматически продлевать окно до последнего
месяца источника. Из-за этого было принято решение исключить весь последний год (2026).


## Пересобрать CSV

Из корня проекта:

```bash
./dataset/export.sh
```

Нужны `psql` и доступ к первичным таблицам. Параметры берутся из
[db.env](../primary-data/db.env), пароль — из `~/.pgpass`, подробнее в
[DB.md](../primary-data/DB.md).
