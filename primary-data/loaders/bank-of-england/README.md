# Bank of England

Таблица `"primary".bank_of_england__raw` содержит финансовые показатели Банка Англии:
ставки, кредитование, ипотечные одобрения, денежные агрегаты и валютные курсы.
Одна строка — значение одного показателя на дату или за период.

## Столбцы

| Столбец | Значение |
| --- | --- |
| `DATE` | Дата наблюдения или обозначение периода, например `31 Jan 2023` |
| `SERIES` | Код показателя. Определяет, что измеряется, с какой частотой, в каких единицах и с какой сезонной корректировкой |
| `VALUE` | Опубликованное значение показателя; единицы зависят от `SERIES` |

Коды обозначают разные экономические ряды. Например, `IUDBEDR` — официальная
ставка Банка Англии за день, а `IUMABEDR` — её среднее за месяц; оба значения в процентах.
Другие ряды могут выражаться в фунтах, тысячах, миллионах или индексных пунктах.
Описание конкретного кода можно найти в [базе BoE](https://www.bankofengland.co.uk/boeapps/database/).

Все поля хранятся как `text`. Пустые значения и `..` не означают ноль.
Исходные значения и повторы сохраняются без расчётов и агрегации.

## Загрузка в БД

`load.py` читает готовые CSV и загружает их в основную БД проекта,
в таблицу `"primary".bank_of_england__raw`. Замена выполняется одной транзакцией.
Выгрузки и параметры доступа остаются локально и исключены из Git.
Из корня репозитория (Python 3.14 и `uv`):

```powershell
$loader = 'primary-data/loaders/bank-of-england'
uv run --with-requirements "$loader/requirements.txt" python "$loader/load.py" --snapshot "$loader/data/<snapshot>" --env-file primary-data/.env
```

Подключение: [DB.md](../../DB.md). `--env-file` принимает строки `PG*=значение`
без `export` и кавычек. В нём указываются параметры основной БД проекта.
