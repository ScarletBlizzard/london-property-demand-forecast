# 🏠 Загрузчик: HM Land Registry — Price Paid Data

Наполняет таблицу `"primary".hm_land_registry__price_paid` сделками с недвижимостью 
по Лондону. Подключение к БД и пароль — в [DB.md](../../DB.md).

Нужны `psql` и `python3`, сторонние библиотеки не требуются.

## Как пользоваться

Запускать из каталога загрузчика:

```bash
cd primary-data/loaders/hm-land-registry__price-paid

./load.sh              # полная загрузка с нуля: ~1 час на выгрузку, ~5 минут на заливку
RELOAD=1 ./load.sh     # то же, если таблица уже не пуста
./load_year.sh 2026    # обновить один год (~несколько минут)
```

**`load.sh`** качает `pp-complete.csv` (~5.2 ГБ) и заливает всю историю с 1995 года.
На непустой таблице останавливается — чтобы случайно не затереть общие данные,
для переиницилизации нужен явный `RELOAD=1`.

**`load_year.sh`** качает годовой файл (110–160 МБ) и заменяет год целиком, не
трогая остальную историю. Повторный запуск безопасен и дублей не создаёт.
Основной сценарий — раз в месяц обновлять текущий год: Land Registry досылает
сделки с лагом в несколько месяцев.

Параметры подключения берутся из общего [db.env](../../db.env). Чтобы залить в другую базу,
переопределите `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER` или `DATA_DIR` в окружении.
