# ONS / Nomis

Загрузчик получает население, рынок труда, заработки и Claimant Count из [Nomis](https://www.nomisweb.co.uk/)
для **33 районов Лондона**, включая City of London. По умолчанию берутся все категории,
меры и доступные периоды четырёх выбранных наборов. Это не весь каталог Nomis.

Данные лежат в схеме **`primary`**, каждый набор — в отдельной таблице.
Исходные названия столбцов и значения сохраняются; все поля имеют тип `text`.
Расчётов, заполнения пропусков и удаления повторов нет.

| Набор | Таблица | Периоды в снимках от 17.10.2026 | Строк |
| --- | --- | --- | ---: |
| `NM_31_1` — население | `nomis__population_raw` | 1981–2025, по годам | 321 750 |
| `NM_17_5` — Annual Population Survey (APS) | `nomis__labour_market_raw` | Январь–декабрь 2004 — апрель 2025–март 2026 | 23 521 344 |
| `NM_30_1` — Annual Survey of Hours and Earnings (ASHE) | `nomis__earnings_raw` | 2002–2025, по годам | 4 410 450 |
| `NM_162_1` — Claimant Count | `nomis__claimant_count_raw` | Январь 1986 — август 2026, по месяцам | 6 570 432 |

Всего **34 823 976 строк**, из них **11 418 211** с заполненным `OBS_VALUE`.
Строки включают разные меры, пересекающиеся группы и пропуски, поэтому это не число
независимых наблюдений. Для ранних лет населения и заработков добавлена историческая
география источника; классификации районов пока не объединяются.

## Как читать столбцы

Одна строка — одно значение для выбранных периода, района, категории и меры.
**`OBS_VALUE` — само значение**, остальные поля объясняют, к чему оно относится.
Единица зависит от набора, категории и `MEASURES`; тип хранения везде `text`.

### Общие столбцы четырёх таблиц

Эти 22 столбца есть во всех таблицах. Вместе с дополнительными полями ниже они
составляют 34 колонки населения, 28 APS, 40 ASHE и 40 Claimant Count.

| Столбец | Что означает | Единица / формат |
| --- | --- | --- |
| `DATE` | Год, месяц или месяц окончания периода APS | `YYYY` или `YYYY-MM` |
| `DATE_NAME` | Название периода, например `Jan 2023-Dec 2023` | Текст |
| `DATE_CODE` | Код периода; в этих выгрузках совпадает с `DATE` | Код |
| `DATE_TYPE` | Тип временной классификации | Текст `date` |
| `DATE_TYPECODE` | Код типа временной классификации | Код `0` |
| `DATE_SORTORDER` | Позиция периода в сортировке источника | Порядковый номер |
| `GEOGRAPHY` | Внутренний идентификатор территории Nomis | Код |
| `GEOGRAPHY_NAME` | Название района | Текст, например `Camden` |
| `GEOGRAPHY_CODE` | Стандартный код района для сопоставления с другими источниками | Код GSS, например `E09000007` |
| `GEOGRAPHY_TYPE` | Название географической классификации | Текст |
| `GEOGRAPHY_TYPECODE` | Версия классификации районов | `424` — районы апреля 2023 года; `464` — историческая версия |
| `GEOGRAPHY_SORTORDER` | Позиция района в сортировке | Порядковый номер |
| `MEASURES` | Код вида значения: показатель, процент, числитель, знаменатель или точность | Код; расшифровки ниже |
| `MEASURES_NAME` | Название вида значения | Текст, например `Value`, `Percent`, `Confidence` |
| `OBS_VALUE` | Опубликованное значение | Человек, %, процентные пункты, GBP, часы или рабочие места — зависит от строки |
| `OBS_STATUS` | Код наличия и качества значения | Код |
| `OBS_STATUS_NAME` | Объяснение статуса, в том числе причины пропуска | Текст |
| `OBS_CONF` | Код конфиденциальности | Код; `F` означает, что публикация разрешена |
| `OBS_CONF_NAME` | Расшифровка конфиденциальности | Текст |
| `URN` | Идентификатор записи Nomis; может повторяться | Код, не уникальный ключ |
| `RECORD_OFFSET` | Позиция записи внутри одного запроса API | Номер с нуля |
| `RECORD_COUNT` | Общее число записей конкретного запроса API | Строки, шт.; не население и не обязательно размер всей таблицы |

### Население — `nomis__population_raw`

Оценки населения по году, району, полу и возрасту. Дополнительные столбцы:

| Столбец | Что означает | Единица / формат |
| --- | --- | --- |
| `SEX` | Пол: `5` — мужчины, `6` — женщины, `7` — всего | Код |
| `SEX_NAME` | Название группы по полу | Текст |
| `SEX_CODE` | Код группы по полу | Код |
| `SEX_TYPE` | Тип классификации пола | Текст `sex` |
| `SEX_TYPECODE` | Код типа классификации пола | Код `0` |
| `SEX_SORTORDER` | Позиция группы по полу в сортировке | Порядковый номер |
| `AGE` | Возрастная группа: например `22` — 16–64 года | Код, не возраст в годах |
| `AGE_NAME` | Название возрастной группы | Текст |
| `AGE_CODE` | Код возрастной группы | Код |
| `AGE_TYPE` | Тип возрастной классификации | Текст `age` |
| `AGE_TYPECODE` | Код типа возрастной классификации | Код `0` |
| `AGE_SORTORDER` | Позиция возраста в сортировке | Порядковый номер |

При `MEASURES=20100` значение `OBS_VALUE` — численность в **человеках**;
при `20301` — опубликованный **процент**. Пустые проценты загрузчик не вычисляет.
Итоговые группы вроде «все возрасты» уже включают частные группы; складывать их вместе нельзя.

### Рынок труда — `nomis__labour_market_raw`

APS — обследование населения: занятость, безработица, экономическая активность и другие показатели.
Период охватывает **12 месяцев**, обновляется ежеквартально. Например, `DATE=2023-12`
означает январь–декабрь 2023 года; соседние периоды перекрываются.

| Столбец | Что означает | Единица / формат |
| --- | --- | --- |
| `VARIABLE` | Идентификатор показателя рынка труда | Код |
| `VARIABLE_NAME` | Название показателя и группы населения | Текст |
| `VARIABLE_CODE` | Код показателя | Код |
| `VARIABLE_TYPE` | Тип классификации показателей | Текст `variable` |
| `VARIABLE_TYPECODE` | Код типа классификации | Код `0` |
| `VARIABLE_SORTORDER` | Позиция показателя в сортировке | Порядковый номер |

| `MEASURES` | Что находится в `OBS_VALUE` | Единица |
| --- | --- | --- |
| `20599` — `Variable` | Значение выбранного показателя | % |
| `21001` — `Numerator` | Численность группы в числителе доли | Человек |
| `21002` — `Denominator` | Численность базовой группы в знаменателе | Человек |
| `21003` — `Confidence` | Величина «±» для приблизительного 95%-го доверительного интервала | Процентные пункты |

Основание процента зависит от показателя: например, безработица относится к экономически
активным жителям, а занятость — ко всей соответствующей возрастной группе.

### Заработки — `nomis__earnings_raw`

ASHE — заработки наёмных работников **по месту жительства**, до налогов и удержаний.
Также публикуются часы работы и число рабочих мест. Это не общий доход домохозяйства.

| Столбец | Что означает | Единица / формат |
| --- | --- | --- |
| `SEX` | Категория работников по полу и занятости; например `8` — полная занятость, оба пола | Код |
| `SEX_NAME` | Название категории работников | Текст |
| `SEX_CODE` | Код категории работников | Код |
| `SEX_TYPE` | Тип классификации работников | Текст `sex` |
| `SEX_TYPECODE` | Код типа классификации работников | Код `0` |
| `SEX_SORTORDER` | Позиция категории работников в сортировке | Порядковый номер |
| `PAY` | Вид оплаты или рабочего времени | Код |
| `PAY_NAME` | Название вида оплаты или времени | Текст |
| `PAY_CODE` | Код вида оплаты или времени | Код |
| `PAY_TYPE` | Тип классификации оплаты; так назван у источника | Текст `item` |
| `PAY_TYPECODE` | Код типа классификации оплаты | Код `0` |
| `PAY_SORTORDER` | Позиция вида оплаты в сортировке | Порядковый номер |
| `ITEM` | Вид статистики: медиана, среднее, процентиль и др. | Код |
| `ITEM_NAME` | Название статистики | Текст |
| `ITEM_CODE` | Код статистики | Код |
| `ITEM_TYPE` | Тип классификации статистик | Текст `item` |
| `ITEM_TYPECODE` | Код типа классификации статистик | Код `0` |
| `ITEM_SORTORDER` | Позиция статистики в сортировке | Порядковый номер |

Единицу `OBS_VALUE` определяют **три поля вместе**:

| Условие | Единица / смысл |
| --- | --- |
| `MEASURES=20100`, `ITEM=2, 4, 6–15` | Медиана, среднее или процентиль; единицу задаёт `PAY` |
| Для этих статистик `PAY=1–4` | GBP (£) за неделю |
| Для этих статистик `PAY=5–6` | GBP за час |
| Для этих статистик `PAY=7–8` | GBP за год |
| Для этих статистик `PAY=9–11` | Часов работы в неделю |
| `MEASURES=20100`, `ITEM=1` | Число рабочих мест, шт. |
| `MEASURES=20100`, `ITEM=3` или `5` | Годовое изменение медианы или среднего, % |
| `MEASURES=20301` — `Percent` | Отдельная процентная мера источника, % |
| `MEASURES=20701` — `Confidence` | Коэффициент вариации оценки, %; не интервал «±» в фунтах |

### Claimant Count — `nomis__claimant_count_raw`

Месячная статистика получателей Jobseeker's Allowance и Universal Credit, от которых
требуется искать работу. Это отдельный показатель, он не равен безработице по APS.

| Столбец | Что означает | Единица / формат |
| --- | --- | --- |
| `GENDER` | Пол: `0` — всего, `1` — мужчины, `2` — женщины | Код |
| `GENDER_NAME` | Название группы по полу | Текст |
| `GENDER_CODE` | Код группы по полу | Код |
| `GENDER_TYPE` | Тип классификации пола | Текст `Sex` |
| `GENDER_TYPECODE` | Код типа классификации пола | Код `1000` |
| `GENDER_SORTORDER` | Позиция группы по полу в сортировке | Порядковый номер |
| `AGE` | Возрастная категория; коды отличаются от набора населения | Код |
| `AGE_NAME` | Название возрастной категории | Текст |
| `AGE_CODE` | Код возрастной категории | Код |
| `AGE_TYPE` | Уровень возрастной классификации | Текст, например `Ageband` |
| `AGE_TYPECODE` | Код уровня возрастной классификации | Код |
| `AGE_SORTORDER` | Позиция возрастной категории в сортировке | Порядковый номер |
| `MEASURE` | Показатель: численность или одна из долей | Код `1`–`4` |
| `MEASURE_NAME` | Название показателя, включая основание доли | Текст |
| `MEASURE_CODE` | Код показателя | Код |
| `MEASURE_TYPE` | Тип классификации показателей | Текст `measures` |
| `MEASURE_TYPECODE` | Код типа классификации показателей | Код `1000` |
| `MEASURE_SORTORDER` | Позиция показателя в сортировке | Порядковый номер |

| `MEASURE` | Смысл `OBS_VALUE` при `MEASURES=20100` | Единица |
| --- | --- | --- |
| `1` | Число получателей | Человек |
| `2` | Доля относительно жителей 16–64 лет | % |
| `3` | Доля относительно экономически активных жителей 16+ | % |
| `4` | Доля относительно рабочей силы (`workforce`) | % |

`MEASURE` выбирает показатель, а **`MEASURES`** — вид значения: `20100` (`Value`)
или `20301` (`Percent`). У `MEASURE=4` и у всех `MEASURES=20301` в проверенном снимке
значения отсутствуют; строки сохранены как у источника.

### Пропуски и коды

Пустой `OBS_VALUE` не равен нулю. Причина указана в `OBS_STATUS_NAME`: данные могут
отсутствовать, быть скрыты или статистически ненадёжны. `OBS_CONF` описывает
конфиденциальность, а `MEASURES_NAME=Confidence` — статистическую точность.
Одинаковая буква в разных полях может иметь разный смысл.

Полные справочники категорий и исходные ответы находятся в `data/<snapshot>/`.
Население, ASHE и Claimant Count скачиваются в CSV, APS — в TSV для сохранения кавычек
в названиях. Файлы сжаты в gzip; `manifest.json` содержит состав и статус выгрузки.

## Как запустить

Нужны Python 3.14, `uv` и PostgreSQL. Команды выполняются из корня репозитория.
Настройки подключения — в [DB.md](../../DB.md) и общем [db.env](../../db.env).
`--env-file` принимает строки `PGHOST=...`, `PGPORT=...`, `PGDATABASE=...`, `PGUSER=...`,
`PGPASSWORD=...`, `PGSSLMODE=...` без `export` и кавычек. Bash-файл `db.env`
напрямую в этот параметр не передаётся.

Скачать все четыре набора без записи в БД:

```powershell
$loader = 'primary-data/loaders/nomis'
uv run --with-requirements "$loader/requirements.txt" python "$loader/load.py" --download-only
```

Загрузить готовую выгрузку в локальную БД. Вместо `<snapshot>` подставь папку из вывода
загрузчика; в `data/local-check/local.env` укажи параметры своей локальной БД:

```powershell
$snapshot = "$loader/data/<snapshot>"
uv run --with-requirements "$loader/requirements.txt" python "$loader/load.py" --snapshot $snapshot --env-file "$loader/data/local-check/local.env"
```

Сверить локальные таблицы с рабочей БД без записи:

```powershell
uv run --with-requirements "$loader/requirements.txt" python "$loader/transfer.py" --source-env "$loader/data/local-check/local.env" --target-env primary-data/.env --snapshot $snapshot --check-only
```

Для переноса выполни последнюю команду без `--check-only`. Если наборы скачаны в разные
папки, добавь отдельный `--snapshot <папка>` для каждой. Повторных обращений к API нет:
данные берутся из локальной БД, файлы выгрузки нужны для проверки полноты.
Совпадающие таблицы пропускаются; каждая изменённая таблица заменяется одной транзакцией.
При обрыве переноса незавершённая таблица передаётся заново.

Скачивание продолжается через `load.py --resume <папка> --download-only`.
Если прервалась загрузка файлов в БД, повтори команду с `--snapshot`: сохранённые страницы
будут пропущены. `--dataset <код>` выбирает отдельный набор при новом скачивании.
Остальные параметры — в `--help`, SQL-проверки — в [sql/verify.sql](sql/verify.sql), тесты — в `tests/`.
Данные и файлы с паролями исключены из Git.
