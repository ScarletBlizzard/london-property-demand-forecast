# ONS / Nomis

В схеме `primary` хранятся четыре набора для 33 районов Лондона, включая City of London.
Сохранены исходные категории, меры, периоды и флаги качества данных.

| Таблица | Содержание |
| --- | --- |
| `nomis__population_raw` | Население по полу и возрастным группам, по годам |
| `nomis__labour_market_raw` | Занятость, безработица и экономическая активность (APS), скользящие 12-месячные периоды |
| `nomis__earnings_raw` | Заработки работников по месту жительства, рабочее время и число рабочих мест (ASHE), по годам |
| `nomis__claimant_count_raw` | Получатели пособий, обязанные искать работу (Claimant Count), по месяцам |

## Общие столбцы

Одна строка — значение для периода, территории, категории и меры.

| Столбец | Значение |
| --- | --- |
| `DATE` | Год или месяц; для APS — месяц окончания 12-месячного периода |
| `DATE_NAME`, `DATE_CODE` | Название и код периода |
| `DATE_TYPE`, `DATE_TYPECODE`, `DATE_SORTORDER` | Временная классификация, её код и порядок периода в справочнике |
| `GEOGRAPHY` | Внутренний идентификатор территории Nomis |
| `GEOGRAPHY_NAME`, `GEOGRAPHY_CODE` | Название территории и код GSS для связи с другими источниками |
| `GEOGRAPHY_TYPE`, `GEOGRAPHY_TYPECODE`, `GEOGRAPHY_SORTORDER` | Географическая классификация, её версия и порядок территории в справочнике |
| `MEASURES`, `MEASURES_NAME` | Код и название вида значения: показатель, процент, числитель, знаменатель или точность |
| `OBS_VALUE` | Опубликованное значение; единицы зависят от набора, категории и меры |
| `OBS_STATUS`, `OBS_STATUS_NAME` | Код и описание качества значения, включая причины пропуска |
| `OBS_CONF`, `OBS_CONF_NAME` | Код и описание конфиденциальности публикации |
| `URN` | Идентификатор записи источника; уникальность не гарантируется |
| `RECORD_OFFSET`, `RECORD_COUNT` | Позиция записи и число строк в исходном запросе; это служебные поля, не статистические показатели |

## Столбцы категорий

| Набор | Столбцы | Значение |
| --- | --- | --- |
| Население | `SEX`, `AGE` | Пол и возрастная группа |
| APS | `VARIABLE` | Показатель рынка труда и группа населения |
| ASHE | `SEX`, `PAY`, `ITEM` | Группа работников; вид оплаты или рабочего времени; статистика — среднее, медиана, процентиль и др. |
| Claimant Count | `GENDER`, `AGE`, `MEASURE` | Пол, возрастная группа и показатель — число получателей или доля в определённой группе населения |

Каждое поле категории сопровождается `*_NAME` (название), `*_CODE` (код источника),
`*_TYPE` и `*_TYPECODE` (классификация и её код), `*_SORTORDER` (порядок в справочнике).
`MEASURE` в Claimant Count выбирает показатель, а `MEASURES` — вид значения.

Население измеряется в людях или процентах. APS содержит проценты, численности групп
и погрешность в процентных пунктах. В ASHE единицы определяются видом оплаты и статистики:
фунты за час, неделю или год, часы работы, рабочие места либо проценты.
Показатель точности ASHE — коэффициент вариации в процентах.
Claimant Count содержит число получателей или их долю; он не равен безработице по APS.

Все поля имеют тип `text`. Пустой `OBS_VALUE` не равен нулю; причину нужно смотреть
в `OBS_STATUS_NAME`. Повторы, пересекающиеся категории и исторические версии географии
сохранены. Соседние периоды APS перекрываются.

## Загрузка в БД

`load.py` читает готовые CSV/TSV и загружает их в основные таблицы Nomis
схемы `primary` в БД проекта. Замена таблиц выполняется одной транзакцией.
Для версии 2 повтор команды после обрыва продолжает загрузку с сохранённых страниц.
Выгрузки и параметры доступа остаются локально и исключены из Git.
Из корня репозитория (Python 3.14 и `uv`):

```powershell
$loader = 'primary-data/loaders/nomis'
uv run --with-requirements "$loader/requirements.txt" python "$loader/load.py" --snapshot "$loader/data/<snapshot>" --env-file primary-data/.env
```

Подключение: [DB.md](../../DB.md). `--env-file` принимает строки `PG*=значение`
без `export` и кавычек. В нём указываются параметры основной БД проекта.
Параметры загрузки доступны через `--help`.
