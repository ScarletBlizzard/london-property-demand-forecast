# 🚇 Загрузчик: TfL — Public Transport Accessibility Levels (PTAL)

Наполняет таблицы `"primary".tfl__ptal_lsoa_2023` и `"primary".tfl__ptal_lsoa_2015`
индексом транспортной доступности по LSOA Лондона. Также поддерживает
`primary.tfl__ptal_borough_2015` — готовую агрегацию TfL по районам. Подключение к БД и пароль —
в [DB.md](../../DB.md).

Нужны `psql` и `curl`, сторонние библиотеки не требуются.

## Как пользоваться

```bash
cd primary-data/loaders/tfl__ptal

./load.sh               # все три набора
./load.sh 2023          # LSOA 2023
./load.sh 2015          # LSOA 2015
./load.sh 2015-borough  # готовый PTAL 2015 по 33 районам
```

Загрузка занимает секунды: три файла вместе меньше 1 МБ. Каждый запуск полностью
заменяет таблицу. PTAL — статический срез, а не ряд: внутри релиза ничего не
досылается, поэтому догружать нечего и повторный запуск безопасен. Если
`Last-Modified` в источнике не изменился, файл заново не скачивается.

Параметры подключения берутся из общего [db.env](../../db.env). Чтобы залить в другую
базу, переопределите `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER` в окружении.

## Что загружается

| Релиз | Таблица | Строк | География | Лицензия |
| --- | --- | --- | --- | --- |
| 2023 | `tfl__ptal_lsoa_2023` | 4 994 | LSOA 2021 | OGL v3.0 + атрибуция OS |
| 2015 | `tfl__ptal_lsoa_2015` | 4 835 | LSOA 2011 | OGL v2.0 |
| 2015-borough | `tfl__ptal_borough_2015` | 33 | Borough | OGL v2.0 |

В итоговом датасете **релиз 2015 используется до января 2023, затем — релиз 2023**.
Релиз 2015 рассчитан по периоду 2008–2014 и не знает ни Elizabeth line, ни продления
Northern line, ни Barking Riverside. Для дат до 2015 это приближение; переключение
по году релиза не восстанавливает точную дату его публикации.

Для 2015 на [London Datastore](https://data.london.gov.uk/dataset/public-transport-accessibility-levels-24rz6)
есть готовый файл **2015 PTAL Borough** с кодами, названиями и индексом по 33 районам.
Он позволяет обойтись без справочника LSOA → район. Его значения отличаются от
простого среднего по LSOA, поэтому способ агрегации нужно учитывать при сравнении
с релизом 2023. В проверенном открытом каталоге TfL за 2023 найдены агрегаты LSOA,
MSOA и ward; готовый borough-набор не обнаружен.

Итоговый датасет использует готовый borough-набор 2015 напрямую по коду района.
Для 2023 среднее по району рассчитывается из LSOA. Локальный справочник не нужен.

Индексы отдельным файлом не выносим: таблицы небольшие, первичного ключа
по коду LSOA или района достаточно; он объявлен прямо в `ddl_*.sql`.

## Агрегация по районам

Для релиза 2023 используем колонку `borough`, предоставленную TfL, и считаем
среднее `mean_ai` по району. Название района из `lsoa21nm` не извлекаем.
При соединении с другими источниками согласуем написание `&` и `and`.

Релизы 2015 и 2023 — два среза транспортной доступности. Они различаются
периодом расчёта, границами LSOA и способом агрегации, поэтому разницу индексов
не следует интерпретировать как чистый эффект изменения транспортной сети.

## Файлы

| Файл | Назначение |
| --- | --- |
| `load.sh` | скачивание и заливка обоих релизов |

| `sql/verify_<релиз>.sql` | итоговая сводка по строкам, районам и значениям индекса |
