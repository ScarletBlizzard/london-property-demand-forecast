# 🚨 Загрузчик: MPS Recorded Crime — Borough, Ward, LSOA

Наполняет три таблицы схемы `primary` помесячной статистикой зарегистрированных
преступлений Metropolitan Police Service за 2010-04 — 2026-09.
Подключение к БД и пароль — в [DB.md](../../DB.md).

| Таблица | География | Строк |
| --- | --- | ---: |
| `"primary".mps__crime_borough` | район | 215 124 |
| `"primary".mps__crime_ward` | вард | 4 166 508 |
| `"primary".mps__crime_lsoa` | LSOA | 24 458 802 |

Нужен `python3` с `pandas` и `psycopg`, `psql` не требуется:

```bash
python3 -m pip install pandas "psycopg[binary]"
```

## Как пользоваться

Запускать из каталога загрузчика:

```bash
cd primary-data/loaders/mps__recorded-crime

./load.sh                                              # весь конвейер: скачать, проверить, собрать, залить
python3 scripts/06_load_to_postgres.py --dry-run       # проверить собранные файлы без БД
python3 scripts/06_load_to_postgres.py --only borough  # залить одну таблицу: borough, ward или lsoa
```

**`load.sh`** выполняет четыре шага: качает 16 файлов источника в `data/raw` (~230 МБ),
проверяет их и пишет `data/manifest.csv`, собирает хронологию в `data/consolidated`
(~2,6 ГБ, из них LSOA 2,2 ГБ) и заливает её в БД (~5,8 ГБ вместе с индексами).
Повторный запуск безопасен: скачанное не перекачивается, собранное не пересобирается,
существующие таблицы не трогаются. Скрипты ничего не удаляют, поэтому для перезаливки
таблицу нужно удалить вручную.

Каждая таблица заливается в одной транзакции и до `COMMIT` сверяется с CSV: число строк
и сумма по каждому месяцу. При расхождении транзакция откатывается.

Параметры подключения берутся из общего [db.env](../../db.env). Каталог с данными
можно переопределить через `DATA_DIR`.

Исследовательские шаги в `load.sh` не входят и запускаются отдельно, после шага 2:

```bash
python3 scripts/03_compare_schemas.py   # различия категорий, кодов и сумм между файлами
python3 scripts/04_probe_categories.py  # переименования подкатегорий, имена районов, коды вардов
```

## Как собрана хронология

В `london_crime_files.csv` перечислены 16 файлов с data.london.gov.uk. В сборку идут
9 основных, по три на уровень:

| Период | Borough | Ward | LSOA |
| --- | --- | --- | --- |
| 2010-04 — 2020-09 | `3kv` | `11j` | `t25` |
| 2020-10 — 2024-09 | `pg2` | `mmy` | `04d` |
| 2024-10 — 2026-09 | `byz` | `w4e` | `7gv` |

Код — последняя часть имени файла, он записан в колонку `source` каждой строки.

- Если месяц есть в нескольких файлах, берётся самый свежий выпуск: полиция пересматривает
  данные, старый и новый выпуски на перекрытиях расходятся до 1,9 %.
- Длинный формат: строка на территорию, категорию, подкатегорию и месяц. `month` — первое
  число месяца, `count` — число преступлений. Нули как в источнике, строк, которых нет
  в источнике, не добавляется.
- Названия территорий и категорий как в источнике, без очистки и склейки.
- В сборку не вошли дополнительные файлы с подробной классификацией (она есть только до
  2022-01), старый LSOA-файл `e0e053d0` (его перекрывает `t25`, расхождение не больше 0,05 %),
  варды 2001 — 2010 в старых границах и Business Crime.

## Особенности данных

**Взломы жилья** в разные годы записаны под разными подкатегориями `BURGLARY`:

| Подкатегория | Ненулевые месяцы |
| --- | --- |
| `DOMESTIC BURGLARY` | 2010-04 — 2023-07 |
| `RES BURGLARY OF A HOME` | с 2018-11 |
| `RES BURGLARY OF UNCONNECTED BUILDING` | с 2022-01 |
| `BURGLARY - RESIDENTIAL` | единичные записи в 2024 — 2026 |

Для непрерывного ряда их нужно складывать. В 2018 — 2023 годах ненулевые и старая, и новые
подкатегории, поэтому перед использованием стоит проверить ряд на двойной счёт.
Подкатегории взломов жилья есть и в выгрузках LSOA, их суммы близки к уровню районов.

```sql
select borough, month, sum(count) as residential_burglary
from "primary".mps__crime_borough
where major_category = 'BURGLARY'
  and minor_category in ('DOMESTIC BURGLARY', 'RES BURGLARY OF A HOME',
                         'RES BURGLARY OF UNCONNECTED BUILDING', 'BURGLARY - RESIDENTIAL')
group by borough, month;
```

Остальное:

- `PUBLIC FEAR ALARM OR DISTRESS` с 2024-02 пишется с запятой: `PUBLIC FEAR, ALARM OR DISTRESS`.
- **Borough.** Кроме районов есть подразделение аэропорта под тремя именами
  (`London Heathrow and London City Airports`, `Heathrow`, `Aviation Policing`) и `Unknown`.
- **Ward.** Коды в современных границах. Один код может встречаться с разными написаниями
  названия или под разными районами, например `Whitechapel` в Hackney и Tower Hamlets.
  Есть служебные коды `N/K`, `NON ATHENA FORCE` и 17 старых кодов `E05000` после 2020-10.
  На стыке 2020-10 сумма по вардам растёт примерно на 1,6 %, с 2024-03 она на 3 — 10 %
  ниже суммы по районам. Так в исходных файлах.
- **LSOA.** Район записан кодом `E09` в колонке `borough_code`. Сумма по LSOA на 3 — 5 %
  ниже суммы по районам, в 2023-10 провал до 0,88 — он есть в обоих выпусках.
- City of London в источник не входит, см. [README источников](../../README.md).
